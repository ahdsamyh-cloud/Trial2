# IT administrator (Super Admin)

Admin accounts are separate from daily accounts and **cannot hold legal roles**. You manage users and settings but can't see legal content.

* **Users → New user:** username, name, email, department, roles. Unit roles need a unit; Auditors need an expiry date. Give the temporary password in person (shown once), or the user receives a 24-hour setup link when email is on.
* **Change roles, reset password / two-factor, unlock, disable:** all need your password + code again, and are logged. Role changes sign the user out and alert you (and the HoD for sensitive roles).
* **Leavers:** *Leaver checklist* shows how much open work the person has. Ask the HoD or Unit Head to reassign it, then **Disable**. Use **Emergency disable** for security incidents.
* **Sessions:** see and revoke any user's sessions.
* **Configuration:** departments, holidays, SLA targets, request types, templates, document types, law firms, courts, regulators, retention periods, system settings.
* **Access review:** Users → *Access review (Excel)* every quarter.
* **Audit log:** you see system events (sign-ins, user and role changes, configuration) only.
* Operational procedures: `docs/RUNBOOK.md`; installation: `docs/IT_SETUP.md`.
